电阻表示导体对电流的阻碍程度，单位为欧姆。电阻的标称值通常按 IEC 的 E 系列选取，E24 多用于通用电路，E96 的标称值分布更密，常用于精密电路。选型时应综合考虑封装、公差、温漂和额定功率。热敏、光敏和压敏电阻分别可用于温度检测、光控和浪涌保护。  在电路中，串联电阻可限流，串联电阻网络可按比例分压，并联电阻可分流。上拉和下拉电阻分别设定默认高、低电平，阻值需兼顾静态功耗、灌电流和信号上升时间。采样电阻将电流转换为可测量的压降，也可为恒流控制提供反馈。  电阻与电容可组成 RC 滤波网络，其时间常数由阻值与电容值的乘积决定。高速信号可通过源端串联或接收端并联匹配电阻来减小反射与振铃。0 Ω 电阻可用作 PCB 跳线，也可作为调试和电流测量时的可拆连接点。
